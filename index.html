2. 核對辨識明細

OCR 會看錯健保碼、藥名或總量。逐列修正後選「已核對」；未核對的列也會出現在匯出檔並標示待核對。辨識不到時可用「新增一筆」手動填入。

3. 下載 CSV

明細格式相容於原本 Python 程式的「--from-detail」欄位；加總依健保碼及單位分組。健保碼或總量無效的資料不計入加總，畫面會提示。

此工具只協助整理候選資料；訂購與調劑前仍須由人員核對原始處方、健保碼、品項和數量。支援 JPG、PNG 及手機瀏覽器能讀取的照片格式。

4. 拍照數藥錠（測試版 r13）

將藥錠分開平放、四周留空，從正上方拍照。系統在照片上逐顆標記；相接、重疊、反光、透明或與背景同色的藥錠仍可能算錯，請逐一核對標記。

自動結果不準時，可調整模式、背景差異及最小面積，或按「圈選一顆校準」，依序點一顆完整藥錠的左上角、右下角。校準後仍可點標記刪除、點空白補上一顆。金屬盤上的白色藥錠可選「白色藥錠／金屬藥盤」。重疊的藥粒仍需手動核對。
