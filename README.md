# 處方拍照轉 CSV

用手機拍攝處方藥品明細，在瀏覽器辨識健保碼、藥名與總量，人工核對後下載 CSV。

## 開啟網站

啟用 GitHub Pages 後，網站網址是：

**https://yuyao62.github.io/prescription-ocr-csv/**

在此儲存庫選擇 **Settings → Pages → Build and deployment**，把 **Source** 設為 **Deploy from a branch**，再選 **main**、**/(root)** 並按 **Save**。請稍候，回到 Pages 設定頁查看發布網址。

## 手機使用

1. 開啟上面的網站，按「開啟相機拍照」，或選擇多張相簿照片。
2. 等候辨識完成。首次使用需要連網下載 OCR 程式及繁體中文、英文語言資料。
3. 逐筆對照原始處方，修正健保碼、藥品名稱、總量及單位，再將狀態改成「已核對」。
4. 下載「辨識明細 CSV」或「藥品加總 CSV」。無效的健保碼或數量不會列入加總。

辨識不到的品項可按「新增一筆」手動輸入。頁面一次最多加入 12 張照片，每張上限 25 MB；可分批處理。

## CSV 欄位

- **辨識明細**：檔名、健保碼、藥品名稱、總量、單位、狀態、收錄(1/0)、辨識原文。欄位可供原本的 Python 統計程式使用 `--from-detail` 重新加總。
- **藥品加總**：依健保碼與單位分組，列出總量、筆數、待核對筆數及藥名不一致提示。

## 資料與限制

照片在使用者的瀏覽器中處理，不會由此頁上傳到 GitHub；CSV 下載到使用者自己的裝置。重新整理會清除尚未下載的明細。這是公開網站，**不要把處方照片、病人資料或匯出的 CSV 上傳到儲存庫**。

OCR 可能誤讀文字或數字。訂購、配藥及調劑前，請由人員核對原始處方與匯出結果。本工具不會自動寫入 Google 試算表或 Drive。

網站使用 [Tesseract.js](https://github.com/naptha/tesseract.js) 在瀏覽器執行辨識。辨識程式及語言資料由外部 CDN 載入，因此首次開啟需保持網路連線。

## 拍照數藥錠

在頁面第 4 區拍攝或選擇藥錠照片。先將藥錠彼此分開，放在單色且對比明顯的背景，四周留空。頁面會估計顆數並在照片上編號；可調整「背景差異」與「最小面積」重新計算。

點綠色標記可刪除誤判，點漏掉的藥錠可補上一顆；「復原上一步」可撤銷最近一次手動修正。確認後可下載獨立的「數藥記錄 CSV」。數藥結果不會寫入處方加總。

相接、重疊、透明、白色藥錠與白色背景，或有花紋與陰影的背景都可能造成誤判。請逐顆核對照片標記與實物；數藥記錄會保留「待人工核對」狀態。
